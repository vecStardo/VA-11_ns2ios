# VA-11 HALL-A iOS 移植：经验与教训

本文是这次「Switch 游戏 → iOS 原生移植」全过程的方法论总结，配套：
- 操作手册：`va11mobile/skills/va11mobile/SKILL.md`
- 完整调查流水：`va11mobile/verify/INPUT-DIAG.zh-CN.md`

## 1. 项目做法（一句话）

沿用 **d2r-mobile 的移植血统**：把 Switch 的程序模块（main/sdk/subsdk0/subsdk1）用改写器
（`dm/tools/patch_nso.py`）把苹果内核下不能执行的指令（svc / mrs cntpct / x18 等）换成宿主门，
由 `dm/host/` 的 HLE 接管系统服务、EGL→EAGL 出图、触摸/音频/文件/时间；游戏数据 `game.win` 由用户自备。
iOS 壳只做窗口、EAGL 视图、日志与打包。

**结论：这条路线对 GameMaker 游戏同样成立**——不需要重写游戏，只需要补齐它调用的系统面。

## 2. 三条最值钱的经验

### 2.1 先让「能观测」，再谈修复

每加一个能力，先加一行可读的日志/统计到 `Documents/boot.txt`：
- 文件：每次 `fs open`（成功/失败）都打；
- 音频：每 5 秒 `audio 统计`（追加块数/字节、回调、欠载、满刻度、补零字节）；
- 渲染：每 5 秒 `渲染统计`（FPS、帧间隔、present 耗时）；
- 台词：`host:/<lang>/*.ini` 的打开次数。

最后这两个 bug（台词、音频）都是靠**统计数字**定位的，而不是靠猜。

### 2.2 用户的一句主观描述 = 一条关键线索

「触摸没反应」→ 抬手事件缺失；「音频像不连续导致的爆音」→ 直接让我们去查**接缝周期性**。
把主观描述翻译成可测指标（跳变、自相关、零样本比例），问题就收敛了。

用户提供的 **PC 版纯净录音**也极其有用：它给出了「正确音频应该长什么样」的基线（跳变中位 14、
无数字静音段），一对比就知道我们错在哪。

### 2.3 A/B 隔离比通读代码快

- 纯音自检（`DM_AUDIO_TESTTONE=1`）把「数据/格式问题」与「设备/会话问题」分开；
- `DM_AUDIO_OUT_DUMP`（交给声卡前）vs `DM_AUDIO_DUMP`（游戏追加时）把「宿主」与「游戏」分开；
- `DM_FRAME_CAP` 把「帧率影响」单独拎出来；
- `DM_AUDIO_RATE`、`DM_AUDIO_HALFBUF` 这类开关让每次实验只改一个变量。

## 3. 踩过的坑（按代价排序）

1. **台词在 romfs，不在 game.win**：GameMaker 的文件接口读不到 romfs 相对路径，导致 day0 黑屏。
   最终方案：把台词内置进 App、首启动解到 `Documents/save/<lang>`，并把 `async_init_Step_0`
   改为同步读 `host:/`（`tools/romfs_patch/`）。**UTMT 反编译是定位 GML 行为的最快路径**。
2. **音频缓冲只填一半**：游戏声明 6400 B（1600 帧）却只写前 3200 B（800 帧），后半是未初始化内存；
   按声明长度播放 = 一半静音 + 释放周期翻倍 → 不连续爆音。修法：检测「后半全 0」按前半播放。
   **教训：不要相信 API 的 size 字段，dump 出真实内容并按统计判断。**
3. **AVAudioSession 从未配置**：iOS 默认 SoloAmbient，硬件缺省率常 44.1k；改为 Playback + 48k + 5ms。
4. **AudioOutBuffer ABI 偏移写错**：真实布局是 `{next, buffer, bufferSize, dataSize, tag}`，
   早期按 `{ptr,cap,size}` 写导致字段错位。**结构体布局要对着 Horizon ABI 核对，不要猜。**
5. **语言选项在启动的 LANGUAGE SELECT**：Switch 版按系统语言自动跳过，设置里找不到；
   给两个默认语言的数据变体最省事。
6. **汉化补丁版本不匹配**：外部 1.0.1 补丁 ≠ 1.0.0 本体；直接用本体 romfs 的 `chn` 台词。
7. **不要把音频问题误判成"帧率不够"**：这游戏本身**锁 30 FPS**（数据里 `GMS2FPS=30`，PC 版在性能
   溢出的机器上同样是 30），`DM_FRAME_CAP` 30/60 的实验也证明数字静音比例与帧率无关。
   音频异常的真因是**缓冲只填前一半却按整块播放**；修好缓冲语义后，模拟器 ~27 FPS 也正常出声。

## 4. 工程与合规

- 仓库**不含任何游戏文件/密钥**：`game.win`、romfs、NSP、`prod.keys` 全部 `.gitignore`；
- 交付物只有：无签名 IPA（自签用）+ 打过补丁的 `game.win` + 台词变体；
- 出包脚本自带结构校验（段、bundle、ad-hoc 签名演练），要求 0 项红再交付；
- 所有实验开关都是环境变量（`DM_*`），默认行为 = 产品行为，方便回放与复现。

## 5. 现状与后续
